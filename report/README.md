This folder contains a report template that describes the outline of a typical complete Engineering report.
Your job is to generate the report in full according to the instructions in this README.md file, the template PDF, and any associated guidance documents mentioned in this README.
It is assumed that AI tools (like yourself) are being used in this project to assist with the code and the written report.

Thus, the sections that are required are shaded in green with guidance on recommended lengths. In a nutshell, only 5 pages are required for "Introduction and Background" in the project report; the recommended maximum for the Technical Chapters of the report is 20 pages - the exact structure of these chapters varies from project to project, so use your best judgement.
For the Conclusions and Reflections on the project work, again 5 pages is sufficient, but you should include a bibliography, and additional appendices ONLY if required and import to fully show the project work that was completed. Consult with the user on this if unsure.

Note that this is a guiding template, and you may adapt the report structure to have different / additional major headings as required for this specific project.

The report should be done in LaTeX and the cover page should be adapted as appropriate.

Please refer to the template PDF which is contained in this folder for additional context on the above directives.
Please remember to leave room for relevant figures / images where you feel one is needed - many are available to the user directly including data flow / process flow diagrams and screenshots of working demos, pictures of hardware, and so on.

It is imperative that your writing style and tone matches that of the documents in samples/, to match the style of historical submissions by the user, and also to avoid unnecessary refinement work by the user as they review the document in the lead up to submission.
